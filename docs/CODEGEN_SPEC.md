# Code Generation Specification: C99, WebAudio, and VST3/CLAP

WaveForge includes an integrated transpiler pipeline that converts visual node graphs into multiple production targets: standalone C99 headers, single-file HTML5 WebAudio players, and C++ VST3/CLAP plugin projects.

## 1. C99 Standalone Header Specification (`waveforge_synth.h`)

### Design Principles
1. **Zero External Dependencies**: Pure ISO C99 standard library only (`<math.h>`, `<stdint.h>`, `<stdlib.h>`, `<string.h>`).
2. **Deterministic Memory Footprint**: All node state structures, ring buffers, and filter registers are preallocated within a single `WaveForgeSynth` struct.
3. **Embeddable Anywhere**: Can be embedded directly into C/C++ game engines, microcontrollers (Teensy, Daisy Seed, ESP32), or WebAssembly targets.

### C API Contract
```c
#include "waveforge_synth.h"

// 1. Initialize instance with sampling rate
WaveForgeSynth synth;
waveforge_synth_init(&synth, 44100.0f);

// 2. Note triggering
waveforge_synth_note_on(&synth, 60, 0.9f); // Note on: Middle C, 0.9 velocity
// ...
waveforge_synth_note_off(&synth);          // Note off

// 3. Audio buffer processing
float out_left[128];
float out_right[128];
waveforge_synth_process(&synth, out_left, out_right, 128);
```

### Native and WebAssembly Compilation
```bash
# Native standalone test runner with WAV output
clang -O3 -DWAVEFORGE_STANDALONE waveforge_synth.h -o synth_runner.exe -lm
./synth_runner.exe

# Standalone WebAssembly binary
clang --target=wasm32 -O3 -nostdlib -Wl,--no-entry -Wl,--export-all waveforge_synth.c -o waveforge_synth.wasm
```

## 2. WebAudio / HTML5 Single-File Player Specification

Generated by `AudioWorkletGenerator`:
- Produces a single, self-contained HTML file.
- Runs without any web server or external script download.
- Employs the browser Web Audio API (`AudioContext`) with script processors or worklets.
- Embeds an interactive dark-mode UI with virtual keyboard keys and real-time gain/meter display.

Generate via CLI:
```bash
waveforge export-html techno_acid_seq -o player.html
```

## 3. VST3 and CLAP C++ Plugin Project Specification

Generated by `PluginGenerator`:
- Exports a complete CMake build tree (`CMakeLists.txt`, `src/*`, `include/waveforge_synth.h`).
- Sets `CMAKE_CXX_STANDARD 20` and `CMAKE_C_STANDARD 99`.
- Wraps the C synthesizer state inside an object-oriented class `WaveForgeSynthPlugin`.
- Maps patch parameters to normalized $[0.0, 1.0]$ plugin parameters for host DAW automation.
- Dispatches MIDI NoteOn and NoteOff events with velocity sensitivity.
- Supports buffer processing with arbitrary frame block sizes.

Generate via CLI:
```bash
waveforge export-plugin acid_303 --out-dir build_plugin --name AcidSynth303
```
